# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and technical.
- Critique ideas, not people.
- No harassment, discrimination, or vendor bashing.
- Do not ask for or share platform signing keys, MFi credentials, or
  proprietary software.

## Scope

Issues, pull requests, discussions, and any project-related communication.

## Enforcement

Report unacceptable behaviour to the maintainer via the contact address on
the GitHub profile. Reports are handled confidentially. Maintainers may
remove comments, close issues, or block accounts that violate this policy.
