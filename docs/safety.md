# 安全与合规

## 1. 操作风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| 车机变砖 | 替换 `/system` 下的 HAL 与系统应用 | 完整备份；保留官方固件；先确认可进 recovery |
| 原车功能失效 | 蓝牙电话、蓝牙音乐、方控、语音助手可能不可用 | 接受或回滚 |
| 保修失效 | 修改系统分区通常会导致保修条款失效 | 自行评估 |
| 行车安全 | 调试期间不要在道路上操作车机 | 停车、驻车状态下操作 |
| 电瓶亏电 | 长时间调试（数小时）可能耗尽电瓶 | 接充电器或保持发动机运转 |

## 2. 法律与合规

- 本项目仅用于**你自己拥有的车辆**上的**互操作性研究**。
- 不要用于规避版权保护、破解付费服务或分发他人软件。
- 各地区对车辆电子系统改装的规定不同，请自行确认当地法规
  （年检、保险、道路交通安全法等）。
- 修改车机可能影响车辆的电磁兼容性与功能安全认证，**不要**在公共道路
  上使用未经认证的改装进行营运活动。

## 3. 第三方软件

本项目**不包含**以下内容，也不提供获取途径：

| 内容 | 原因 |
|---|---|
| DiPlay APK（`com.shihab.diplay`） | 商业软件，版权归作者 |
| DiPlay MFi 资产（`identity.pk8`、`certificate.p7b`） | Apple MFi 授权材料 |
| AOSP 预编译二进制 | 体积大，应从官方获取 |
| 车机平台签名密钥 | 安全敏感，且通常不可合法获取 |
| 车机固件 / OTA 包 | 厂商版权 |

若你修改并分发 DiPlay，请自行确认其许可条款。本项目只提供
**针对已合法获取的副本进行互操作性修补的方法**。

## 4. 隐私

部署脚本不会上传任何数据。日志中可能包含：

- 蓝牙 MAC 地址
- Wi-Fi SSID
- 配对设备名称

分享日志前请自行脱敏：

```bash
sed -E 's/([0-9A-F]{2}:){5}[0-9A-F]{2}/AA:BB:CC:DD:EE:FF/g' logcat.txt > clean.txt
```

## 5. 安全建议

- 调试用的无线 ADB 用完即关（`setprop service.adb.tcp.port ""` 或重启）
- 不要在车机热点上使用弱密码
- 不要把 platform 签名密钥放在仓库或云盘
- 提交前运行 `python tools/check_secrets.py`
